# The local-time universe

The critic run also ships as a local-time `Universe`: eight stations — four failure modes, four
verification criteria — one per day, each verdict a keyframe.

| file | role |
| --- | --- |
| `src/universes/critic.ts` | Typed module, `bigint` nanoseconds |
| `src/universes/types.ts` | The structural `Universe` subset, no private dependency |

The module is generated by `scripts/universe-data.mjs` from the same model run as the charts, so
the timeline cannot drift from the report. The shape matches `james-gibson/local-time`'s
`Universe`, but is type-only — the seed builds from a clean checkout with no dependency on the
private repo.

```sh
npm run universes   # runs the model, writes src/universes/critic.ts
```

Every keyframe's significance maps the verdict: `violation` is 0.9, `drift` is 0.6, `pass` is
0.35. A violation is the high-significance event; a pass is the low one. See
[the universe page](/universes).

# Silverskin — a documentation site that ships itself

Silverskin is the onion's outer layer: the skin that protects and identifies. As an isotope, it is
a documentation site whose content, navigation, guard and deploy are all one checkout.

- **Content is files.** One Markdown file is one page; the file path is the URL.
- **Navigation is derived.** There is no nav array to edit.
- **The guard is the gate.** A weakened check invalidates every other claim.
- **Deploy is push.** GitHub Pages, no runtime service.

This seed is a silverskin instance. Take the content model, the guard chain, and the deploy.

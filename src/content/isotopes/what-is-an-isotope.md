# What an isotope is

An isotope is a named procedure with slots — the parameters an agent cannot guess. Its identity is
the name, never a position: `cornichon` survives reordering, insertion and deletion; `02` does not.

The four tests:

1. **It is small enough to lift whole.** One page, one pattern, no hidden dependencies.
2. **It is named, permanently.** The name is in URLs and QR codes; a rename is a break.
3. **It declares its slots.** The empty values are the questions an agent asks.
4. **It announces its presumptions.** Runtime, platform, permissions — an attack surface is only
   assessable against a stated runtime.
